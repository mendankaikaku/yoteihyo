予定入力Excel 全体統合アプリ

予定入力HTMLから出力したExcel（シート名「予定入力」）と、生徒対応表（学年・生徒番号・名前・よみがな・担当・高校・備考。予定Excelの生徒名は苗字だけ/苗字＋名1文字でも部分一致）と結果Excelを合わせて、横軸カレンダー・縦軸生徒名の全体予定表を作ります。各日は左に予定、右に結果を表示します。Excelファイルは外部送信せず、このブラウザ内だけで処理します。
または、Excelファイル/フォルダーをここへドラッグ
推奨構造：予定表/生徒名.5月30日-6月5日.xlsx、または予定表/生徒名/週ごとのExcel.xlsx。Chrome/Edgeならフォルダー選択できます。
対応表は学年ごとにシートが分かれていても読めます。各シートは左端から 学年 / 生徒番号 / 名前 / よみがな / 担当 / 高校 / 備考 の順で読み取ります。1行目に見出しがあってもOKです。外部送信はしません。
列名：生徒番号 / 名前 / 学年 / 区分 / 学習内容 / 学習結果 / いいね! / 日時。複数日分は同じシートに下へ追記するのが推奨です。シートを日別に分けても全シートを読み取ります。
