統合用アプリの使い方 何をするにしても①→②→③→④でうまくいく

① 復元保存復元フォルダーを選ぶだけ。打ち込み結果・毎日更新・対応表・全員分リスト・全体予定表・Comiruを自動で読み取る。
② 統合予定、結果、模試、イベント、Comiru回答をまとめる。ログに未照合や衝突が出たら確認する。
③ 保存結果履歴をJSONに保存。前日の毎日更新.xlsxは上書きしても、履歴から復元できるようにする。
④ 出力2週間出力、1か月出力、全員分リスト、毎日更新を必要に応じてダウンロードする。

毎日更新

  1. アプリとは関係なく毎日更新フォルダから毎日更新.xlsxに前日の結果を貼り付ける。
  2. 毎日更新.xlsxを上書き保存して閉じる。
  3. このアプリで①フォルダー読取 → ②統合 → ③結果履歴を保存。
  4. ④毎日掲示を押して、出たExcelを開いて印刷。
  5. 毎日掲示.xlsxは毎日"掲示"フォルダに保存

2週間出力(受講が全員予定通り進んでいるかを確認できるカレンダーです)と模試科目リストについて

  1. ①フォルダー読取 → ②統合 → ③保存。
  2. ④2週間出力を押す。
  3. 出力したエクセルを開いて、手修正の有無にかかわらず「全体予定表」フォルダーへ上書きでも新しいファイルとしてでもいいので保存する。
  4. 模試科目リストは「④ 科目リスト出力」から別Excelで出力する。そのエクセルを開いて、科目変更などで手修正の有無にかかわらずExcelは保存復元フォルダ直下の「科目リスト」フォルダへ保存する。次回出力時には手修正・追加行・追加列を復元するようになっている。

全員分リスト

  1. ①フォルダー読取 → ②統合 → ③結果履歴を保存　→ ④全員分リスト。
  2. フロントで聞いた内容は、アプリ関係なく全員分リストフォルダから直接エクセルを開いて全員分リストに手入力してよい。
  3. もしくはこのアプリで出力してできたエクセルを開いて編集し、全員分リストフォルダの「全員分リスト」エクセルに上書き保存。
  4. このアプリを用いたほうが最新の内容を反映できる。(∵個人の打ち込み結果も読み取っているし、全員分リストエクセルも読み取っている。)
  5. 次回読み取り時に、該当生徒の該当セルの手修正をできるだけ維持するようになっている。
  6. もしも聞き取り漏れや打ち込みミスなどで、面談入力用のアプリで入力した内容やコミルのアンケート結果と科目リストの内容が異なった場合、科目リストのほうが優先される。

絶対に忘れないこと

  • 統合後は必ず③結果履歴を保存する。
  • 手修正したExcelは対応フォルダーへ戻す。
  • Comiru CSVは「Comiru」フォルダーへ入れる。
  • 見出し行(1行目)は消さない。列の追加・並び替えはOK。
右側の「条件を決める」「表示を選ぶ」「ログ」は必要なときだけ確認します。普段は左の①フォルダー読取、上部の②統合・③保存・④出力だけで進めます。

1. 初見用ダイジェスト

目的 入力用で作った個人予定、毎日更新、全員分リスト、科目リスト、Comiruをまとめて、掲示・印刷用Excelを出す。
基本 画面上部の番号順に押す。
重要 毎日更新を使う日は、統合後に「③結果履歴を保存」を押す。
  1. ①フォルダーを読み取るで保存復元フォルダーを選ぶ。
  2. ②統合するを押す。
  3. ③結果履歴を保存を押す。
  4. ④出力から必要なExcelを出す。

2. 普段の操作手順

2週間予定表

①→②→③→④2週間出力。手修正したExcelは全体予定表フォルダーへ戻す。

全員分リスト

①→②→④全員分リスト。フロント確認結果を手入力し、全員分リストフォルダーへ戻す。

毎日掲示

毎日更新.xlsxへ前日結果を貼る → ①→②→③→④毎日掲示。出たExcelを毎日掲示フォルダーへ保存。

4. 優先順位・上書きルール

基本： 最新ファイルの具体値が勝つ。空欄は具体値を消さない。
個人Excel重複： 同じ生徒・同じ予定なら更新日時が新しいものを優先。ただし空欄で上書きしない。
全員分リスト： 手修正を維持する。回答・状態・Comiru・科目変更は消えにくい設計。
科目リスト： 手修正された科目詳細を復元する。
毎日掲示： 当月・前日など、出力ごとの日付ルールを優先する。

5. 各出力の目的

2週間出力
基準日の前後2週間を掲示・確認用に出す。
1か月出力
基準日の前後1か月を見る。長めの予定確認用。
期間指定出力
開始日〜終了日を自分で決めて出す。
全員分リスト
模試・イベントの当日/後日/不受験、Comiru回答、科目変更を一覧で確認する。
科目リスト出力
模試の受験科目を別Excelで管理する。
毎日掲示
連続実施・高速基礎ランキング・講座修得・完全修得を掲示用に出す。

6. エラー・困ったとき

  • 出力ボタンが押せない： まだ①フォルダー読取か②統合が終わっていない。理由表示を見る。
  • 毎日掲示が出ない： 毎日更新.xlsxがない、result_history.jsonがない、③保存忘れの可能性。
  • 予定が抜ける： 入力用の保存忘れ、打ち込み結果フォルダーに戻していない、シート名違い。
  • 名前が合わない： 対応表の氏名・生徒番号・フォルダー名の表記ズレ。
  • 手修正が戻らない： 保存先フォルダー違い、見出し行削除、列名変更、ファイル名変更が原因になりやすい。
