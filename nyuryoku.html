予定入力用の使い方
①
生徒名助手名欄に担任助手名を入れて「生徒一覧」を押すと担当生徒をまとめて生徒名欄へ反映できます。生徒名欄には生徒名だけを入れます。
②
前回復元保存復元フォルダーを選んで、前回の予定・備考・模試・イベント・コメントを戻します。
③
入力受講、高マス、問題集、模試、イベント、今週の方針、達成できなかった理由を入力します。
④
保存席を外す前に必ず保存します。画面上で入力編集した人全員が保存されます。

面談準備印刷

  1. 助手名欄に担任助手名を入れて「生徒一覧」を押すか、今日面談する生徒名を入力します。(複数人可)
  2. 前回復元を押します。
  3. 面談準備印刷を押します。
  4. 印刷設定は A4縦・両面・長辺とじ です。
各生徒A4 2枚想定です。1枚目表に先週の予定と結果、裏に今週の計画表(生徒が記入)、2枚目表（3ページ目）は必ず面談フロー、2枚目裏は合格設計図を入れます。週面シートExcelは読み取りません。1枚目は面談時に生徒に記入させ、2枚目は面談時助手が持っておきます。

面談中にやること

  • 模試ComiruとイベントComiruをその場で回答させます。
  • 生徒は面談準備シートに書き込みます。
  • 助手は模試やイベントのチェックボックスを埋めます。
  • 合格設計図に変更があれば、助手が持っている面談準備シートにも書きます。

面談後の打ち込み

  1. 面談シートを回収してコピーします。
  2. 原本は生徒に返却します。
  3. コピーを打ち込みボックスに集めます。
  4. アプリで ①生徒名 → ②生徒欄を作る → ③復元 → 手打ち → ④保存。
  5. 「面談内容コピー」を押してPOSへCtrl+Vします。(2画面にしたほうが楽かも)
  6. 入力後はコピーした紙は生徒ファイルに入れます。

絶対に忘れないこと

  • 入力したら必ず保存します。
  • 保存復元フォルダーを選んで保存します。
  • Comiru回答は面談中に済ませます。
必要なフォルダ構造

最初に作るフォルダー

  • 保存復元フォルダー

保存復元フォルダー

太字のフォルダー名は、アプリが自動で探す名前なので基本的に変更しないでください。
保存復元フォルダー ├─ 打ち込み結果 │ └─ 担任助手フォルダ │ └─ 助手名 │ └─ 生徒名 ├─ 毎日更新 ├─ 対応表 ├─ 全員分リスト ├─ 毎日掲示 ├─ 全体予定表 ├─ 科目リスト ├─ json └─ Comiru
  • 入力用の保存・復元では、この保存復元フォルダーを選びます。
  • 統合用も、この保存復元フォルダーを選ぶだけで自動振り分けします。
  • Comiru CSVは「Comiru」フォルダーに入れます。
  • 毎日更新用のExcelは「毎日更新」フォルダーに入れ、ファイル名は「毎日更新.xlsx」にします。
  • 手修正した全員分リストは「全員分リスト」フォルダーへ戻します。手修正した模試科目リストは「科目リスト」フォルダーへ戻すと、次回復元で入力欄の科目にも反映します。
  • 「マスタ」フォルダーは今の運用では不要です。

担任助手・生徒フォルダー

保存復元フォルダー └─ 打ち込み結果 └─ 担任助手フォルダ ├─ 助手A │ ├─ 生徒A │ │ ├─ 合格設計図.pdf │ │ └─ 合格設計図.xlsx │ └─ 生徒B └─ 助手B └─ 生徒C
  • 生徒フォルダー名は、アプリに入力する生徒名と合わせます。
  • 合格設計図はPDF優先、なければExcelを使います。
  • 週面シートExcelは不要です。面談準備印刷の3ページ目は常に面談フローを印刷します。

迷ったら守ること

  • 保存・復元では「保存復元フォルダー」を選びます。
  • 印刷では「打ち込み結果/担任助手フォルダ/助手名」内の生徒フォルダーを使い、合格設計図を自動で探します。週面シートは使いません。
  • Excelを手修正したら、対応するフォルダーへ戻します。
  • 太字のフォルダー名は変更しないでください。

模試マスタ

模試名・日付・対象学年/高校/担任助手/生徒を登録します。高校/助手は対象生徒名へ一括追加するためだけに使い、対象生徒名が未選択の模試は生徒の入力欄にも印刷にも表示しません。模試マスタでは週開始日から3週間以内の模試だけ表示し、科目型だけを選択します。生徒入力欄・面談準備印刷・統合用の科目リストでは、その科目型から科目チェックを自動表示します。
