個人JSON 模試・イベント履歴だけ全削除ツール

保存復元フォルダーの json 内にある student_*.json と group_*.json から、個人別の exams / events だけを空にします。
消すもの
・個人JSON直下の exams / events
・グループJSON内の studentData[生徒名].exams / studentData[生徒名].events

消さないもの
・予定、教材、備考、未達理由、コメント
・模試マスタ、イベントマスタ、科目型、対象生徒履歴
・result_history.json、毎日更新履歴
今回の安定版
フォルダー読み取りは、統合用でうまくいった旧方式 webkitdirectory をメインにしました。
この方式はブラウザの制限で直接上書きできないので、削除済みJSON＋バックアップ入りZIPをダウンロードします。ZIPを展開して json フォルダーに戻してください。
Chrome/Edgeで直接上書きできる環境だけ、下の「直接削除モード」も使えます。

予備：直接削除モード

もし上の方式でZIP置き換えが面倒なら使えます。ただし環境によってはフォルダー選択が動きません。
ZIP方式の使い方：①フォルダー読取 → ②確認 → ③ZIP作成 → ZIPを展開 → 中の json フォルダーを保存復元フォルダーの json に上書き。
ZIP内には json_backup_exam_event_cleanup_日時 も入るので、元JSONも残ります。
